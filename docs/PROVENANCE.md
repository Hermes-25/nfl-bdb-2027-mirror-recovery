## Changes made for publishing

The portable notebook’s four embedded Markdown figures made its source larger than Kaggle’s accepted limit. A Kaggle-specific copy replaces only those attachment references with the actual uploaded figure URLs and removes the embedded image payloads. All 45 code cells remain byte-identical. The portable copy retains its attachments for offline reading.

The Kaggle writeup uses the uploaded images. Inline notation was converted to readable Unicode because Kaggle’s writeup preview displayed inline dollar-delimited math literally; both numbered display equations were retained. GitHub’s manuscript uses local figure paths and the original mathematical notation.
